# PDF 阅读器

在左侧栏新增「PDF」面板：

- 导入 PDF（点击或拖拽），书架管理，自动记住阅读进度。
- 单页阅读：目录书签跳转、上下页、跳页、缩放（自适应宽度）。
- 划词后右键选择「翻译」或「解释」，结果流式显示在右栏卡片，并保存为划线标注；文字高亮回显，卡片可跳回原页。
- 内置截图小工具：点 ✂ 或按 S 在页面上框选一块区域，输入问题（或用「解释这块 / 翻译图中文」快捷动作）发给能看图的模型，回答流式显示并保存截图卡片。扫描版 PDF 没有文字层时，这就是阅读的入口。
- 文本模型与截图模型分别可指定；无需单独的 API Key。

数据保存在本机 `~/.dsh/pdf-reader/` 下。
