# PDF Reader

Adds a PDF panel to the left sidebar:

- Import PDFs by click or drag; the shelf remembers reading progress.
- Single-page reading: outline jumps, page stepping, page jumps, and zoom (fit width).
- Select text and right-click to translate or explain. Results stream into note cards and persist as highlights; the text stays highlighted and a card jumps back to its page.
- Built-in screenshot tool: click ✂ or press S, drag a region on the page, type a question (or use the Explain / Translate-text quick actions), and send it to an image-capable model. Answers stream in and persist as screenshot cards. On scanned PDFs without a text layer, this is the reading entry point.
- The text model and the screenshot model are separately configurable; no separate API key.

Data lives under `~/.dsh/pdf-reader/`.
