# @deepseek-ai/dsh-experimental-api-text-to-speech

English | [中文](README.zh.md)

The authenticated Remote that serves the synthesis capability to browser clients: catalog and readiness follow, preparation controls, and `synthesize(text)` returning canonical base64 WAV. It validates text limits before calling a provider and never activates an Agent.
